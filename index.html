Setup
  1. Open Paperclip and select your company.
  2. Open configuration for your research agent.
  3. Add a custom MCP server with the URL above.
  4. Save and verify OSIRIS tool discovery.
  5. Send a research command from CommandOS.

OSIRIS Intelligence

Custom MCP endpoint for selected Paperclip agents

https://osirisai.live/api/mcp

In Paperclip, open Connectors, add a custom MCP server using this URL and Streamable HTTP, then grant it only to selected agents. Public intelligence tools need no OSIRIS key. OI prediction tools require provider headers X-OI-Provider and X-OI-Key on the connector.
